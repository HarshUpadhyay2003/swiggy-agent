# Swiggy AI Copilot — Future Roadmap

## Status
All items listed below represent **Future Phase 2 Innovations** beyond Demo V1. Feature development for Demo V1 is frozen under Stage RC-1.

---

## Post-Demo Phase 2 Roadmap

### 1. Merchant Personalization & Customization
- Tailor recommendations based on user merchant loyalty and local delivery radius.

### 2. Learning User Preferences & Long-term Memory
- Store historical order frequency, dietary habits, and favorite items across sessions.

### 3. Vector Similarity Search & Hybrid Retrieval
- Integrate FAISS / Qdrant vector database for dense embedding search alongside structured catalog filtering.

### 4. Collaborative Filtering & Social Proof
- Rank items based on popular combinations ordered by nearby users.

### 5. Multi-Agent Planning & Execution
- Decompose complex multi-person group ordering requests across multiple sub-agents.
